# Staff Blood Inventory Management

## BloodDononerApp – Staff Module

### Overview
The Staff Blood Inventory screen enables authorized hospital staff to view and manage available blood stock at their assigned hospital.

### Key Features
- Display inventory for all eight ABO/Rh blood groups.
- Retrieve hospital blood stock from Firebase Firestore.
- Identify the staff member's assigned hospital.
- Update blood stock using an input dialog.
- Validate blood stock inputs.
- Save inventory changes to the hospital record.
- Display updated stock values.

### Technologies Used
- Kotlin
- Android XML
- Firebase Authentication
- Firebase Firestore
- Material Design Components

### Main Files
- `StaffBloodInventoryActivity.kt` – Inventory management logic.
- `activity_staff_blood_inventory.xml` – Blood inventory interface.
- `dialog_update_blood_stock.xml` – Stock update dialog.
- `res/drawable/` – Blood inventory UI resources.
