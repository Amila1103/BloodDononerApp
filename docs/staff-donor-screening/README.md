# Staff Donor Screening

## BloodDononerApp – Staff Module

### Overview
The Staff Donor Screening screen allows hospital staff to record preliminary donor screening information before continuing with the blood donation process.

### Key Features
- Display donor and appointment information.
- Record donor health screening responses.
- Review recent illness, medications, and previous donations.
- Enter additional screening notes.
- Select a final screening decision.
- Validate required screening responses.
- Save screening results to Firebase Firestore.
- Continue to the donation recording process when applicable.

### Technologies Used
- Kotlin
- Android XML
- Firebase Firestore
- Material Design Components

### Main Files
- `StaffDonorScreeningActivity.kt` – Donor screening logic and validation.
- `activity_staff_donor_screening.xml` – Screening form interface.
- `res/drawable/` – Supporting UI resources.
