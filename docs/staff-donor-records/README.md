# Staff Donor Records

## BloodDononerApp – Staff Module

### Overview
The Staff Donor Records screen provides hospital staff with access to blood donation records associated with their hospital.

### Key Features
- Retrieve donation records from Firebase Firestore.
- Display donor information and blood groups.
- Search donor records.
- Filter and organize donation records.
- View donation dates and status information.
- Display summary and empty-state information.

### Technologies Used
- Kotlin
- Android XML
- Firebase Authentication
- Firebase Firestore
- Material Design Components

### Main Files
- `StaffDonorRecordsActivity.kt` – Donor record retrieval and filtering logic.
- `activity_staff_donor_records.xml` – Main donor records interface.
- `item_staff_donor_record.xml` – Individual donor record layout.
- `res/drawable/` – Interface backgrounds and icons.
