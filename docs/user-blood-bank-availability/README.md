# Blood Bank Availability

## BloodDononerApp – User Module

### Overview
The Blood Bank Availability screen allows users to explore hospital blood bank information and check available blood stock by blood group.

### Key Features
- Retrieve hospital blood bank records from Firebase Firestore.
- Search blood banks using the search interface.
- Switch between Nearby and All views.
- Filter blood banks by ABO/Rh blood groups.
- Display available blood stock quantities.
- Show blood group demand and donation information.
- View additional hospital blood bank details.
- Access emergency blood request and donation actions.
- Refresh hospital information when returning to the screen.

### Technologies Used
- Kotlin
- Android XML
- Firebase Firestore
- Material Design Components

### Main Files
- `BloodBankAvailabilityActivity.kt` – Blood bank data loading and filtering.
- `activity_blood_bank_availability.xml` – Main availability interface.
- `item_blood_bank.xml` – Individual blood bank layout.
- `res/drawable/` – Blood group selection and tab backgrounds.
