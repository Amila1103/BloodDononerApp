# Staff Record Donation

## BloodDononerApp – Staff Module

### Overview
The Staff Record Donation screen allows hospital staff to enter and save blood donation details after the relevant donation process.

### Key Features
- Enter donation and donor identification details.
- Record donor name and blood group.
- Select the donation type.
- Enter donation amount and date information.
- Display the associated hospital.
- Validate required donation fields.
- Save donation records using Firebase Firestore.
- Provide confirmation and error feedback.

### Technologies Used
- Kotlin
- Android XML
- Firebase Authentication
- Firebase Firestore
- Material Design Components

### Main Files
- `StaffRecordDonationActivity.kt` – Donation entry, validation, and saving.
- `activity_staff_record_donation.xml` – Donation recording interface.
- `ic_staff_record_donation.xml` – Donation icon.
