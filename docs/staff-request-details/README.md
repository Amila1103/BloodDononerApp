# Staff Emergency Request Details

## BloodDononerApp – Staff Module

### Overview
The Staff Request Details screen enables hospital staff to review emergency blood requests and perform request management actions.

### Key Features
- Display the emergency request ID and required blood group.
- View required blood units, urgency, and request information.
- Display requester and hospital details.
- Verify emergency blood requests.
- Reject requests through confirmation actions.
- Start donor matching for eligible requests.
- Mark applicable requests as fulfilled.
- Update request statuses through Firebase Firestore.

### Technologies Used
- Kotlin
- Android XML
- Firebase Authentication
- Firebase Firestore
- Material Design Components

### Main Files
- `StaffRequestDetailsActivity.kt` – Request management and status updates.
- `activity_staff_request_details.xml` – Request information layout.
- `res/drawable/` – Status and interface resources.
