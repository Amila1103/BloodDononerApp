# Staff Donor Matching

## BloodDononerApp – Staff Module

### Overview
The Staff Donor Matching screen helps hospital staff identify and contact potential donors for blood requests.

### Key Features
- Display blood request information.
- Retrieve potential donor records using Firebase Firestore.
- Present donor names and blood group information.
- Show previous donation information.
- Contact donors through the phone dialer.
- Send donor notifications with confirmation.
- Display matching donor results in an organized interface.

### Technologies Used
- Kotlin
- Android XML
- Firebase Authentication
- Firebase Firestore
- Android Intent System

### Main Files
- `StaffDonorMatchingActivity.kt` – Donor matching and communication logic.
- `activity_staff_donor_matching.xml` – Main matching interface.
- `item_staff_matching_donor.xml` – Donor result item layout.
- `res/drawable/` – Matching interface resources.
