# Staff Notifications

## BloodDononerApp – Staff Module

### Overview
The Staff Notifications screen provides a notification interface for hospital staff within the BloodDononerApp.

### Key Features
- Display notification-related interface sections.
- Present notification categories using blood donation, appointment, and emergency icons.
- Provide a Mark All as Read control.
- Display user feedback for notification actions.
- Support navigation back to the previous screen.

### Technologies Used
- Kotlin
- Android XML
- Material Design Components

### Main Files
- `StaffNotificationsActivity.kt` – Notification screen interactions.
- `activity_staff_notifications.xml` – Main notification layout.
- `ic_staff_blood_bag.xml` – Blood-related icon.
- `ic_staff_calendar.xml` – Appointment icon.
- `ic_staff_emergency.xml` – Emergency icon.

### Implementation Note
The current screen includes notification UI and interaction feedback. Persistent notification synchronization would require additional backend logic.
