# Staff Appointment Details

## BloodDononerApp – Staff Module

### Overview
The Staff Appointment Details screen allows hospital staff to review individual blood donation appointments and manage donor check-in.

### Key Features
- Display appointment ID and current status.
- View donor information and blood group.
- Display appointment date, time, and donation center.
- Confirm donor check-in.
- Update appointment information through Firebase Firestore.
- Continue to the donor screening process.

### Technologies Used
- Kotlin
- Android XML
- Firebase Firestore
- Material Design Components

### Main Files
- `StaffAppointmentDetailsActivity.kt` – Appointment details and check-in logic.
- `activity_staff_appointment_details.xml` – Appointment details interface.
- `res/drawable/` – Supporting UI resources.
