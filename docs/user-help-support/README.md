# Help & Support

## BloodDononerApp – User Module

### Overview
The Help & Support screen provides users with educational information, guidance, and assistance related to blood donation and application features.

### Key Features
- Search available help topics.
- Learn about blood donation and donor eligibility.
- View information about the blood donation process.
- Access blood group information.
- Read emergency blood request guidance.
- Access frequently asked questions.
- View privacy-related information.
- Access contact and support information.
- Open detailed help dialogs.
- Display emergency assistance information.

### Technologies Used
- Kotlin
- Android XML
- Material Design Components
- Android Dialog Components

### Main Files
- `HelpSupportActivity.kt` – Help topics, search filtering, and dialogs.
- `activity_help_support.xml` – Main Help & Support interface.
- `dialog_help_details.xml` – Detailed help dialog layout.
- `res/drawable/` – Help cards, search, icons, and dialog backgrounds.
