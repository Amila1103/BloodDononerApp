# Staff Appointments Management

## BloodDononerApp – Staff Module

### Overview

The Staff Appointments Management screen is part of the **BloodDononerApp**, an Android-based Blood Donation Management System.

This module provides an interface for hospital staff to view and manage blood donation appointments.

### Key Features

- View blood donation appointments.
- Display appointment information in an organized layout.
- Access individual appointment details.
- Support appointment tracking and management.
- User-friendly mobile interface for hospital staff.

### Technologies Used

- **Programming Language:** Kotlin
- **Platform:** Android
- **IDE:** Android Studio
- **UI Design:** XML Layouts
- **Project:** BloodDononerApp

### Main Files

| File | Description |
|---|---|
| `StaffAppointmentsActivity.kt` | Staff appointments screen logic |
| `activity_staff_appointments.xml` | Main screen layout |
| `item_staff_appointment.xml` | Appointment list item layout |

Additional XML drawable resources are used for interface styling.

### Module Responsibilities

This module focuses on the Staff Appointments interface and its related screen components within the BloodDononerApp project.
