# Staff Profile Management

## BloodDononerApp – Staff Module

### Overview
The Staff Profile screen provides a dedicated interface for hospital staff to access profile-related options and account actions.

### Key Features
- Display the staff profile interface.
- Provide notification settings and help options.
- Display feedback when selecting profile options.
- Provide a logout action.
- Display a logout confirmation dialog.
- Support navigation back to the previous screen.

### Technologies Used
- Kotlin
- Android XML
- Material Design Components
- Android AlertDialog

### Main Files
- `StaffProfileActivity.kt` – Profile interactions and logout confirmation.
- `activity_staff_profile.xml` – Profile screen layout.
- `res/drawable/` – Profile-related UI resources.
