# Staff Dashboard

## BloodDononerApp – Staff Module

### Overview
The Staff Dashboard provides a centralized interface for hospital staff to access the main blood donation management functions.

### Key Features
- Access emergency blood requests.
- Navigate to donation appointments.
- View blood inventory and stock summary sections.
- Access donor records and record donations.
- Open staff notifications and profile.
- Navigate using the staff bottom navigation bar.
- Display a time-based welcome greeting.

### Technologies Used
- Kotlin
- Android Studio
- XML Layouts
- Material Design Components

### Main Files
- `StaffDashboardActivity.kt` – Dashboard logic and navigation.
- `activity_staff_dashboard.xml` – Main dashboard interface.
- `res/drawable/` – Dashboard icons and backgrounds.
